# Product

## Register

product

## Users

Developers browsing HDFS in VS Code or Cursor, locally or over Remote SSH.

## Product Purpose

Make HDFS files easy to reach from the editor. A WebHDFS or HttpFS connection gives users directory browsing, in-editor previews and streaming transfers to and from their computer or SSH host.

## Brand Personality

Quiet, precise, familiar. Product name: HDFS File Manager. Publisher: `daniel-chenjh`.

## Anti-references

Decorative dashboard cards, permanent explanatory banners, fake progress, ambiguous save locations, recursive scans disguised as filtering.

## Design Principles

- Follow the editor's theme and native navigation patterns.
- Keep connection settings together, and preserve edits after failures.
- Describe only operations the current host can complete.
- File management is available by default; a per-connection Read only switch disables writes. No telemetry.
- Keep each action reversible or explicitly user initiated.

## Accessibility & Inclusion

Follows the editor language by default, with persistent English and Simplified Chinese overrides. Keyboard navigation, visible focus, accessible labels, editor high contrast and reduced motion.
