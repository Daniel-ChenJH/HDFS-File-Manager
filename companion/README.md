# HDFS File Manager Local Transfer

Use files on your computer while **HDFS File Manager** runs on an SSH host. Choose **This computer** as the upload source or download destination in the main extension.

The SSH host connects to HDFS. This companion streams the files you select over the editor's existing SSH connection. A download replaces an existing file only after successful verification.

All settings are in HDFS File Manager. HDFS credentials stay with the main extension. This companion collects no telemetry.

## 简体中文

在 Remote SSH 窗口使用 HDFS File Manager 时，可选择「本机」作为上传来源或下载目标。SSH 主机负责连接 HDFS，组件通过编辑器已有的 SSH 连接传输你选择的文件。下载完整校验后才替换目标文件。

所有设置都在 HDFS File Manager 中管理。HDFS 凭据保存在主扩展，组件不采集遥测。
