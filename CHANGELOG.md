# Changelog

## 0.1.0

- Connect to WebHDFS or HttpFS in VS Code and Cursor. Save multiple connections and verify access before opening a connection.
- Browse with the directory tree, path bar, breadcrumbs, sorting, pagination and current-folder filtering. Star files and folders for quick access.
- Preview text, images and PDFs in the editor. Text controls include search, line numbers, word wrap, encoding selection and JSON indentation. PDF pages scroll continuously.
- Upload and download files or whole folders. Transfers stream in local and Remote SSH windows and preserve empty folders. The transfer list supports cancellation and retry.
- Create folders, rename and delete items. A per-connection read-only setting disables writes.
- Global settings validate and save as they change. Language follows the editor by default, with English and Simplified Chinese overrides.
